# Experimento de mapa gamificado de código abierto

Referencia de arquitectura visual: [Duolingo Next.js de Mohanad AL Faleet](https://github.com/mohannadofficial/duolingo-nextjs), archivo `src/app/(main)/learn/_components/lesson-button.tsx` (licencia MIT, Copyright © 2024 Mohanad AL Faleet).

Este prototipo **adapta la idea de recorrido de ocho posiciones en zigzag, nodos circulares y anillos de progreso** a HTML/CSS/JS propios; no incorpora Next.js, su backend, pagos, usuarios, personajes ni assets del repositorio de referencia. Mantiene el motor local de Cachaste, sus preguntas, progreso y gatito original. La licencia MIT permite adaptar el software conservando el aviso de copyright y licencia en caso de copiar porciones sustanciales.

No mezclar esta rama con la principal hasta comparar capturas Android/iPhone/320 px, verificar navegación y validar que mejora realmente la experiencia. El anillo indica exclusivamente si una misión fue **completada (100%)** o **no completada (0%)**. Las misiones en progreso mantienen su etiqueta textual, sin porcentajes pedagógicos inventados.
