# ¿Cachaste? Web comercial

Rama independiente: `work/cachaste-web-comercial-20261024`. Base Android inmutable: `add8a5979d28cb1f7598767bb4bf1ad7b8328937`.

La web se construye a partir de la distribución educativa original. Los archivos fuente de Android y del motor educativo no se modifican. Cloudflare Pages ejecuta una puerta de acceso que valida Auth y el permiso de Supabase antes de entregar HTML, JavaScript o bancos educativos. La landing y la cuenta son públicas; no existe un permiso Premium concedido por el navegador.

Los datos de progreso se sincronizan por UUID y clave, separados de las puntuaciones competitivas verificadas. Los conflictos de sesiones simultáneas deben resolverse conservando ambos borradores. La candidata Android conserva su progreso local; la futura actualización deberá adoptar el adaptador y las RPC nuevas sin cambiar identidades ni IDs de preguntas.

Mercado Pago se integra con funciones independientes de las de Google Play. Todos los cobros quedan desactivados hasta configurar credenciales, planes, receptor, impuestos y documentos tributarios. No se compran dominios ni servicios.

Dominio confirmado y comprado por el titular: **sitecacho.cl**. Hosting preparado para el proyecto independiente **cachaste-sitecacho** en Cloudflare Pages Free, dentro de su cuenta existente. La automatización rechaza cualquier otro proyecto y no tiene permisos DNS. La zona y conexión Lovable de **somosvillablanca.cl** quedan fuera del alcance de los cambios. Configuración y pasos exactos en [OPERACION.md](OPERACION.md).

Implementación y verificación se registrarán con sus límites reales en el informe de entrega.
